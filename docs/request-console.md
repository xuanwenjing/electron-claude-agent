# 接口日志控制台

在客户端窗口按 macOS `⌘ + ⌥ + L` 或 Windows `Ctrl + Alt + L` 直接打开日志控制台，登录前后都可使用。无需密码或环境变量配置，界面不显示按钮、菜单或快捷键提示。

控制台停靠在右侧，左侧业务页面可继续操作。可查看主进程公共 Request 发出的接口请求，包括地址、方法、请求参数、响应内容、HTTP 状态、业务失败及耗时。日志每 2 秒刷新，可筛选、手动刷新或清空。请求进行中也会显示。

只保留最近 50 条内存记录，内容不截断；重启后清空，不写数据库或日志文件。按原始内容展示请求和响应，不做脱敏；不限制数组数量或嵌套层级，仅对循环引用显示标记。不要用它记录业务原始数据存档。

范围为业务 Request，不包含 electron-updater 下载、浏览器扩展自身网络请求或 Agent SDK 的独立网络请求。
