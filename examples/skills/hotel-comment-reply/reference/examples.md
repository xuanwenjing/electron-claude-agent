# 回复示例

以下示例的酒店名为"湖畔花园酒店"，仅示范写法，不要照抄句子。

## 好评

评分 5，内容："房间很干净，早餐种类多，前台小姐姐很热情，下次还来。"

```json
{
  "reply": "亲爱的宾客，感谢您的五星好评！很高兴房间的整洁度和丰富的早餐让您满意，前台同事的热情服务得到您的认可，我们也会转达给她。期待您下次再来，我们会继续用心为您准备干净舒适的房间和可口的早餐。湖畔花园酒店全体员工",
  "sentiment": "positive"
}
```

```json
{
  "reply": "亲爱的宾客，感谢您的入住与点评！很高兴便利的地理位置为您的出行带来方便。对于走廊声音影响您休息，我们深表歉意，已提醒夜间巡视的同事放轻动作，并在排查走廊区域的隔音情况，后续会持续改进。期待您再次光临，给您更安静的入住体验。湖畔花园酒店全体员工",
  "sentiment": "neutral"
}
```
