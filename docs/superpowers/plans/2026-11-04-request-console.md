# 接口日志控制台

范围：公共 Request 采集最近 200 条内存日志，开发和打包环境均可用；敏感字段脱敏、单条内容限长，不写数据库。客户端登录前后均可打开面板。密码由 CLIENT_LOG_CONSOLE_PASSWORD 配置，主进程校验，未配置隐藏入口。解锁限当前窗口，关闭/刷新锁定，最长 30 分钟。

1. 添加日志类型和有界内存存储，记录请求开始、成功及错误，测试脱敏与截断。
2. 注册日志 IPC，验证密码、限制失败重试；读取和清空都校验解锁状态，测试拒绝未授权访问。
3. 添加全局日志面板：密码输入、请求列表、详情、筛选、刷新、清空和锁定关闭。
4. 更新配置说明，执行编译、类型检查及请求/权限回归测试。
